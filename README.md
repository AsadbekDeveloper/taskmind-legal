# taskmind-legal

Static legal pages for the TaskMind Android app, served by GitHub Pages:
privacy policy, terms of service and the account-deletion page, in English,
Uzbek and Karakalpak. The app links to `/privacy.html`, `/terms.html` and
`/delete-account.html`; the same URLs go into the Play Console listing.

The support address is asadbekdeveloper@gmail.com (also in the app's
`LegalLinks`). Keep the pages in step with the app's actual data handling and
the Play Data Safety form.
